# Political Notebook

A long-term research repository for developing, testing, and recording political ideas from first principles.

## Purpose

This repository is primarily a structured knowledge base for the owner and AI agents. It is not currently intended as a finished public publication.

The project will examine first principles, policy questions, documented party positions, evidence, arguments, and an evolving personal position.

## Structure

- `01-first-principles/` — foundational questions.
- `02-policy-domains/` — policy taxonomy.
- `03-parties/` — descriptive party research.
- `04-evidence/` — sources and evidence notes.
- `05-analysis/` — comparative analysis.
- `06-my-position/` — evolving personal position.
- `07-open-questions/` — unresolved questions.
- `08-archive/` — superseded material.

## Status

Proof-of-concept stage. Structure and methodology will evolve as the workflow is tested.
