# Instructions for AI agents

This repository is a long-term political research knowledge base. AI agents may read, analyse, and, where explicitly authorised, modify it.

## Core rules

1. Do not add personal or confidential information. This is a public repository.
2. Distinguish FACT, CLAIM, INTERPRETATION, and NORMATIVE JUDGEMENT.
3. Prefer primary sources where available.
4. Date time-sensitive information.
5. Do not silently rewrite significant changes in position.
6. Do not invent evidence, quotations, sources, or citations.
7. Attribute political parties' claims rather than treating them as independently established facts.
8. Keep analysis separate from source material.
9. Use British English and clear, machine-readable Markdown.
10. Do not make changes to `06-my-position/` that purport to represent the owner's views unless explicitly authorised.
11. Record uncertainty rather than speculating.

## Research pattern

Question → First principles → Definitions → Background → Documented positions → Evidence → Arguments for → Arguments against → Analysis → Provisional conclusion → Unresolved questions → Sources

## Editing

Prefer small, comprehensible commits. Preserve source provenance: title, author/publisher, publication date where known, URL, and access date where useful.
